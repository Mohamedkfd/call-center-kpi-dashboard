# Call Center KPI Dashboard (Power BI)

## Overview

This project analyzes call center performance using key KPIs such as service level, call handling ratio, abandon rate, and average speed of answer (ASA).

## Key Insights

* High call handling ratio (98.7%) indicates strong operational efficiency
* Identified performance variation across months
* Highlighted top-performing agents and low performers
* Detected agents with higher abandon rates indicating improvement opportunities

## Features

* KPI tracking dashboard
* Agent performance analysis
* Monthly trends
* Project efficiency comparison
* Top performers ranking

## Tools Used

* Power BI
* DAX
* Data Modeling
